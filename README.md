# Многослойный персептрон с нуля

Реализация многослойного персептрона на NumPy для бинарной классификации
рака молочной железы (Breast Cancer Wisconsin Diagnostic). Без PyTorch,
TensorFlow, Keras и sklearn — всё с нуля.

## Требования

- Python 3.10 или новее
- pip

## Установка

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

pip install -r requirements.txt
